Embed your Fito Agents AI website assistant on your WordPress site using your Agent ID.

== Description ==

Fito Agents AI Chat is the official WordPress connector for Fito Agents. It allows you to seamlessly integrate your custom AI agents into any WordPress website without touching code.

**Key Features:**
* Easy setup: Just paste your Agent ID.
* Global injection: Automatically appears on all pages.
* Selective exclusion: Disable the widget on specific pages (like Checkout or Account).
* Shortcode support: Use `[fito_agent]` to place the assistant anywhere.
* Fully Customizable: Match the theme and brand color of your business.

**Note:** This plugin requires an active account on [Fito Agents](https://fitoagents.com).

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the **Fito Agents** menu in the admin sidebar to configure your settings.
4. Paste your **Agent ID** from your Fito Agents dashboard.
5. Save and visit your site!

== Frequently Asked Questions ==

= Where do I find my Agent ID? =
Log in to your Fito Agents dashboard, go to "My Agents", select your agent, and visit the "Embed & Share" page. You'll see your unique Agent ID there.

= Does the plugin include the AI? =
No, the AI is hosted securely on FitoAgents.com. This plugin simply connects your WordPress site to our platform.

= Can I customize the colors? =
Yes! You can change the primary brand color and the theme (Light/Dark) directly from the plugin settings page.

= How do I use the shortcode? =
Simply add `[fito_agent]` to any page or post. You can also override the ID: `[fito_agent id="YOUR_ID"]`.
